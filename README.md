# 🥔 PotatoCHIP-8

A simple, modern **CHIP-8 emulator** written in C++.

PotatoCHIP-8 is a learning-focused emulator that implements the classic CHIP-8 virtual machine, capable of loading and running `.ch8` ROMs.

---

## 📖 What is CHIP-8?

**CHIP-8** is a simple interpreted programming language created in the 1970s for the COSMAC VIP. It’s widely used today as a beginner-friendly introduction to emulator development.

- 35 instructions (2 bytes each)
- 4KB memory
- 16 registers
- 64×32 monochrome display
- Hex-based keypad (0–F)

---

## ✨ Features

- ✅ Full CHIP-8 instruction set
- ✅ ROM loading support
- ✅ CPU, memory, and stack emulation
- ✅ Basic display rendering (64×32)
- ✅ Input handling (hex keypad)
  ✅ Basic debug logging

## ⚙️ Building

### Requirements

- C++20 compiler ( I make use of the std::format library ) 
- CMake ≥ 3.20

### Build Steps


```bash
cmake -S . -B build
cmake --build build
```

## ⌨️ Keypad Layout

<br>

The CHIP-8 expects a Hex-Keypad laid out like this

```
1 2 3 C
4 5 6 D
7 8 9 E
A 0 B F
```

<br>

I have mapped this keypad to the keyboad in this layout

```
1 2 3 4
Q W E R
A S D F
Z X C V
```
